# Smart Bus Coordination System

## 🚌 Problem Statement

Our university's bus service operates on only three fixed departure 
times — **1:00 PM, 4:00 PM, and 6:00 PM**. However, class schedules 
vary significantly across sections, with some classes ending as early 
as 10:00 AM and others extending well into the afternoon.

This mismatch causes two major issues for students:

1. **Departure wastage** — A student whose class ends at 2:00 PM has 
   to wait until 4:00 PM for the next bus, wasting nearly 2 hours.
2. **Arrival wastage** — Students often have to arrive much earlier 
   than needed since bus timings don't align with their class start 
   times.

This problem is especially significant for students who commute long 
distances and rely entirely on the university bus service. Missing a 
bus often means waiting 2-3 hours with no productive use of that time, 
which also raises safety concerns during evening hours.

This project aims to solve this problem using a C++ based system that 
intelligently matches class end-times with available bus schedules, 
using core Object-Oriented Programming and Data Structures concepts.
