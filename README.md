# Smart-Bus-Coordination-system
Smart bus scheduling system in C++ using OOP &amp; DSA to reduce student wait times at university.


# Smart Bus Coordination System
## 🚌 Problem Statement

Our university's bus service operates on only three fixed departure 
times — **1:00 PM, 4:00 PM, and 6:00 PM**. However, class schedules 
vary significantly across sections, with different sections ending 
their classes at different times throughout the day (some as early as 
12:00 PM, others as late as 3:00 PM or beyond).

This mismatch causes a major issue for students: a student whose class 
ends at, say, 2:00 PM has to wait until 4:00 PM for the next bus, 
wasting nearly 2 hours doing nothing productive.

This problem is especially significant for students who commute long 
distances and rely entirely on the university bus service. Having to 
wait 2-3 hours after class also raises safety concerns, particularly 
during evening hours, and discourages students from staying back for 
extra academic work or activities.

This project aims to solve this problem using a C++ based system that 
intelligently matches class end-times with available bus schedules, 
built using core Object-Oriented Programming and Data Structures 
concepts.
